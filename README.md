# Manual da Faixa Branca

Guia visual e interativo de jiu-jitsu para quem está começando.

- **Regras de ouro**: etiqueta, higiene e prevenção de lesões
- **Hierarquia das posições**: o que fazer em cada posição e o erro mais comum, com a pontuação IBJJF
- **Técnicas iniciais**: 20 técnicas com passo a passo e checklist de progresso
- **Flexibilidade**: rotinas pré e pós-treino com cronômetro, e uma semana modelo
- **Evoluir rápido**: roteiro do primeiro ano, hábitos e foco do mês
- **Glossário** do tatame

É uma página única (`index.html`), sem dependências. Abra no navegador ou publique com GitHub Pages.

> Este guia complementa as aulas e não substitui o seu professor.
